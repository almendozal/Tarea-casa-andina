CASA ANDINA - ASISTENTE DE VIAJES (PROTOTIPO)

Contenido:
- index.html: las 10 etapas del flujo en una sola página.
- css/estilos.css: estilos y diseño responsive.
- js/app.js: navegación, carga, selecciones, contadores, extras y resumen.
- img/: carpeta reservada para recursos locales.

Cómo ejecutar:
1. Descomprime el ZIP.
2. Abre la carpeta en Visual Studio Code.
3. Abre index.html con Live Server (recomendado).
   También puedes abrir index.html directamente en el navegador.

Notas:
- Las imágenes se cargan desde URLs externas, por lo que requieren conexión a internet.
- Este es un prototipo front-end. No se conecta a disponibilidad real, backend, IA ni pasarela de pago.
- La pantalla final confirma una solicitud de demostración, no una reserva ni un pago real.
